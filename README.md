# chiryoinDB — 整骨院 患者管理シート（プロトタイプ）

整骨院の運営会社向け患者管理シート。会社 → 院 → 患者 の階層、月次シート、権限管理を備えた Web アプリ。

## 起動

```
npm start        # http://localhost:3000  （Node 22.13+、依存パッケージなし）
npm test
```

初回起動時にサンプルデータ（A社/B社、各権限のアカウント）を作成します。
ログインは開発用（アカウント選択）。本番では Google ログインに置き換えます（`DEV_LOGIN=0` で無効化）。

## 実装済み
- 権限: 本部 / 会社管理者 / 院担当者（サーバー側で全APIを検証。他社・他院のデータは参照・更新不可）
- マスター項目（項目1〜）と会社別の使用可否、マスター名称変更は全社に反映
- 患者IDは会社に紐付く連番（`C1-0001`）。同一会社内で氏名+生年月日が重複すると警告
- 月次シート: 新規患者 / 既存患者を分けて表示。翌月は前月内容を自動コピーし「未確認」、院担当者が「継続」「終了」を確認。終了した患者は以降の月に出ない
- 入力制限: 編集できるのは来院回数と有効な項目の値のみ。合計・小計はサーバー計算で、書き込みAPI自体が受け付けない
- 会社管理者は自社の院・アカウントを追加可能

## 本番化の予定
- 認証: Firebase Authentication（Google）。DB: Firestore。ホスティング: Firebase Hosting + Cloud Functions もしくは Cloudflare
- `db.js` と `/api/login` の差し替えで対応（API・画面は流用）
